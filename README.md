# drahmedbekhet.com

Website of Dr. Ahmed Bekhet: Arabic for adult beginners (Quranic Arabic, Conversation, Reading). Plain static HTML served by GitHub Pages.

## Editing
- Pages: `index.html`, `courses.html`, `videos.html`, `articles.html`, `articles/*.html`, `about.html`, `book.html`. Shared look: `style.css`. Small scripts: `main.js`.
- **Videos:** upload to YouTube, then put the video id in the thumbnail button's `data-yt=""` attribute (and remove the "Sample" label).
- **Contact email:** set `CONTACT_EMAIL` at the top of `main.js`. The booking and signup forms open the visitor's email app addressed there.
- Placeholders that still need real content are highlighted in gold, in [square brackets].
